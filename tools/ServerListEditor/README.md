# ServerListEditor

MU Season 6 `ServerList.bmd` 的独立 Windows WPF 编辑器。

打开文件后，在左侧选择服务器组并编辑组名；右侧 15 个线路槽位使用下拉框选择类型。可以新增或删除整个服务器组，但不会自动重新编号已有 ID。保存和另存为都会保留当前文件的记录顺序、描述数据和未知字段，只重写固定 32 字节组名字段及 15 个线路类型字节。组名使用 CP936/GBK 编码，编码后必须少于 32 字节。

项目配置为 .NET 8 `win-x64` 自包含单文件发布。此工具不会修改 MuMain 主工程、客户端资源或 OpenMU。
